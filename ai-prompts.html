任务一 · 提示词工程师两轮迭代：需求漏了 → 参数语言补全

目标配置四项需求：无缝循环 / 3.2s 自动翻且拖动不停 / 圆点可点 / 初始 cube。

第 1 轮最直觉的问法

帮我写一个 Swiper 轮播配置：无缝循环，3.2 秒自动翻页，底部圆点分页器可以点击跳转。
AI 回答：
new Swiper('#wySw4', {
  loop: true,
  autoplay: { delay: 3200 },
  pagination: { el: '#wyPag4', clickable: true },
});
验证结论拖动后自动播放停止、效果仍是 slide——漏了「手动操作后不停止」和「初始 cube」两项。

第 2 轮参数语言定向补全

上一版有两个问题：1) 拖动后自动播放要继续，请加上 disableOnInteraction: false；2) 初始切换效果要求是 3D 立方体，把 effect 设为 cube。重新给完整配置，动画时长 800 毫秒。
AI 回答（最终采纳）：
new Swiper('#wySw4', {
  loop: true,                                  // ① 无缝循环
  effect: 'cube',                              // ④ 初始效果为 cube
  speed: 800,
  autoplay: { delay: 3200, disableOnInteraction: false },  // ②
  pagination: { el: '#wyPag4', clickable: true },          // ③
});
验证结论四项全部通过（页面 swiper-task1.html 底部有真实运行演示），控制台无报错。✅
答辩抽问自答：第一版漏了「拖动不停止」和「cube」；第二轮改用参数名精确表达（disableOnInteraction: false、effect: 'cube'）并指出上版错处让 AI 定向修改；AI 第一次的代码是"不全"而非"错"——autoplay 缺 disableOnInteraction: false（默认 true 拖一次就停），且没写 effect。
T2

任务二 · creative 仿写课堂没讲，AI + 官方示例教会我

参考官方示例 swiper/demo/257-effect-creative.html，为演示四新增第 7 个按钮「creative 电影墙」。要求：上一张缩小左移并带角度、下一张放大右移进场，像电影选片墙。

与 AI 的关键往返creativeEffect 写法

Swiper 的 creativeEffect 里 prev 和 next 分别怎么写？我要"旧片缩小左移带角度、新片放大右移进场"，translate 用像素还是百分比？
AI 回答（要点）：prev/next 各自是一组变换，支持 translate / rotate / scale / opacity / shadow；translate 建议用百分比字符串（相对 slide 自身宽高，不同屏宽观感一致），数字则按像素。最终采纳：
creativeEffect: {
  prev: { shadow: true, translate: ["-40%", "-20%", -250],
          rotate: [0, 0, -10], scale: 0.7, opacity: 0 },
  next: { shadow: true, translate: ["110%", "20%", 0],
          rotate: [0, 0, 6], scale: 1.2, opacity: 0 },
}
验证结论点击「creative 电影墙」按钮后高亮切换、效果重建成功，slides 呈现 rotate/scale 3D 变换，控制台无报错。✅
追问自答（prev / next 的 transform 各控制什么）：prev 控制当前这张被翻走之后去哪——左上退、Z 轴后退、带角度缩小淡出，像把旧海报贴回墙上；next 控制下一张从哪来——从右侧 110% 放大带角度进场，像新海报递到眼前。transform 百分号相对 slide 自身宽高（不是容器），X 轴 100% = 一张卡片宽。
答辩抽问（改 20 度）：把 prev.rotate 的 Z 轴分量从 -10 改成 -20（或 next 的 6 改成 20），单位是度，正负控制倾斜方向。

任务三 · 综合创作第六件展品 + 超纲能力 keyboard

① 用 AI 生成爱达·魔都号横版 16:9 邮轮图（swiper-imgs/aidahao_1.jpg），四个轮播各加第 6 张 slide，结构完整（img + 标题 + 描述）；② 超纲能力选 keyboard 键盘控制。

与 AI 的关键往返keyboard 参数与坑

想给 #wySw4 加键盘方向键控制，但页面很长，希望只有轮播在可视区时按键才生效，怎么配？
AI 第一次回答：加 
keyboard: true
追问：测试发现页面在别处按方向键也会切轮播、和页面滚动打架。AI 修正：写成对象并加 onlyInViewport：
keyboard: { enabled: true, onlyInViewport: true }
验证结论滚动到第 4 个轮播按 ArrowRight 翻页生效；轮播不在视口时按键不误触发；爱达·魔都号第 6 张在四个轮播正常显示，图片 200，控制台无报错。✅
答辩四问 ① 这段代码什么意思？keyboard 模块监听 document 的方向键；enabled 开启功能；onlyInViewport: true 限定只有轮播容器在可视区内才响应，避免长页面滚动时误触发。
答辩四问 ② AI 第一次给的哪里不对、你改了什么？AI 给的 keyboard: true 是全局生效——页面任何位置按方向键都会切轮播。我把简写改成对象写法，补 onlyInViewport: true 限定视口。
答辩四问 ③ 新参数的作用？onlyInViewport 让键盘监听"看位置"：轮播滚出视口就忽略按键，滚回来才恢复，这是简写形式给不了的精细控制。
答辩四问 ④ 现场把 delay 改成指定值？把 autoplay.delay 从 3200 改成 1600：自动翻页间隔缩短一半，动画时长 speed: 800 不变，观感更急促；因为配置抽成了共用函数 jx530_sw4Config(fx)，改一处，初始和所有效果重建后都生效。
