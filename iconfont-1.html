字形即图标

Font Awesome 把几千个图标铸成一款字体：每个图标是字体里的一个字形，占据一个 Unicode 码位。 写下一个类名，就像拣出一个铅字——<i class="fa-solid fa-house">， 由 CSS 的 content: "\f015" 与 @font-face 加载的字体文件共同把它印到页面上。

字体图标是怎样印出来的

一、引入本地化样式文件（已随页面下载到 cdn 目录，无需外网）：

<link rel="stylesheet" href="cdn/fontawesome/6.5.2/css/all.min.css">

二、用类名拣字，fa-solid / fa-regular / fa-brands 分别对应三款字体：

<i class="fa-solid fa-house"></i>

三、字体文件由 all.min.css 里的 @font-face 自动加载（webfonts 目录下的 .woff2 / .ttf）， 图标既然是文字，颜色字号自然也交给 color 与 font-size。
