任务一 · 提示词工程师：让 AI 听懂需求

本任务不写代码，写提示词。把需求"翻译"给 AI，让它生成 new Swiper('#wySw4', {...}) 配置。
作者：金鑫 · 学号 24001010530 · 使用模型 GLM-5.3-Flash

① 无缝循环② 3.2 秒自动翻页且手动操作后不停止③ 圆点分页器可点击④ 初始效果为 cube
📌 使用说明：下面保留了两轮完整的提示词与 AI 回答。第 1 轮按最直觉的方式问， AI 答案大概率有遗漏或错误；第 2 轮针对遗漏定向补全。每轮均粘进页面亲自验证并给出结论， 页面底部的轮播就是第 2 轮最终配置的真实运行效果。
1

需求拆解把题目翻译成 Swiper 参数语言

四项硬性需求

无缝循环 → loop: true　·　3.2 秒自动翻且拖动后不停 → autoplay: { delay: 3200, disableOnInteraction: false }　·　圆点可点 → pagination: { el, clickable: true }　·　初始 3D 立方体 → effect: 'cube'

硬性要求：至少迭代 2 轮，保留每轮提示词与 AI 回答；亲自粘进页面验证每项需求，用截图 + 一句话结论说明验证结果。

2

两轮提示词迭代提示词 → AI 回答 → 验证结论

第 1 轮初版问法 · 最直觉的表达

帮我写一个 Swiper 轮播配置：无缝循环，3.2 秒自动翻页，底部圆点分页器可以点击跳转。
AI 回答（GLM-5.3-Flash）：
new Swiper('#wySw4', {
  loop: true,
  autoplay: { delay: 3200 },
  pagination: { el: '#wyPag4', clickable: true },
});
验证结论（一句话） 粘进页面后能循环、能自动翻、圆点能点——但用手拖动之后自动播放就停了，而且效果还是默认 slide 不是 cube： 第 1 轮漏掉了「手动操作后不停止」和「初始效果 cube」两个需求。

第 2 轮指出遗漏 · 用参数语言定向补全

上一版有两个问题：1) 拖动后自动播放要继续，请加上 disableOnInteraction: false；2) 初始切换效果要求是 3D 立方体，把 effect 设为 cube。重新给完整配置，动画时长 800 毫秒。
AI 回答（最终采纳版）：
new Swiper('#wySw4', {
  loop: true,                                  // ① 无缝循环
  effect: 'cube',                              // ④ 初始效果为 cube
  speed: 800,
  autoplay: { delay: 3200, disableOnInteraction: false },  // ② 3.2s 且拖动后不停止
  pagination: { el: '#wyPag4', clickable: true },          // ③ 圆点可点击
});
验证结论（一句话） 粘进页面刷新后四项全部通过：最后一张继续翻回到第一张、每 3.2 秒自动翻、拖一下松手后继续自动翻、初始即为 3D 立方体效果，控制台无报错。✅

4

答辩抽问 · 自答课堂分就在这三问里

问：你的第一版提示词漏掉了哪个需求？
「手动操作后不停止」和「初始效果为 cube」——只说了"自动翻页"没说拖动之后的行为，也忘了第 4 条效果要求。
问：你是怎么在第二轮里"说清楚"的？
不再笼统描述，用 Swiper 的参数名精确表达：`disableOnInteraction: false`、`effect: 'cube'`，并指出上一版错在哪，让 AI 定向修改而不是重新猜。
问：AI 第一次给的代码错在哪？
不算"错"，是"不全"：`autoplay: { delay: 3200 }` 缺 `disableOnInteraction: false`（该值默认 true，拖一次就停），且没有任何 effect 配置。
