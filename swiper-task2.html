与 AI 的关键往返creativeEffect 怎么写、为什么用百分比

提问第一次接触 creative

Swiper 的 creativeEffect 里 prev 和 next 分别怎么写？我要"旧片缩小左移带角度、新片放大右移进场"，translate 用像素还是百分比？
AI 回答（要点）：prev / next 各是一组变换，支持 translate / rotate / scale / opacity / shadow；translate 建议用百分比字符串（相对 slide 自身宽高，不同屏宽观感一致），写数字则是像素。最终采纳：
creativeEffect: {
  prev: { shadow: true, translate: ["-40%", "-20%", -250],
          rotate: [0, 0, -10], scale: 0.7, opacity: 0 },
  next: { shadow: true, translate: ["110%", "20%", 0],
          rotate: [0, 0, 6], scale: 1.2, opacity: 0 },
}
验证结论（一句话） 在 swiper-task.html 点击「creative 电影墙」按钮后高亮切换、效果重建成功，slides 呈现 rotate/scale 3D 变换，控制台无报错。✅

追问自答实现后用自己的话写下

prev / next 的 transform 各控制什么？
prev 控制"当前这张被翻走之后去哪"：左上退到 -40%,-20%、Z 轴后退 250px、带 -10° 倾斜、缩到 0.7 倍再淡出——像把一张旧海报贴回墙上去。next 控制"下一张从哪来"：从画面右侧 110% 处、放大 1.2 倍带 6° 角像新海报递到眼前，落位恢复正常大小。
transform 的百分号是相对谁的？
相对 slide 自身的宽高（不是容器）：X 轴的 100% = 一张卡片的宽度，所以 "110%" 刚好是从右边一张卡片外进场。
答辩抽问：改一个数值让卡片转 20 度？
把 prev.rotate 的 Z 轴分量从 -10 改成 -20（或 next 的 6 改成 20）即可，单位是度，正负控制倾斜方向。
