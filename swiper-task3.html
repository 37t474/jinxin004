与 AI 的关键往返keyboard 从"能用"到"好用"

提问 → 第一次回答 → 追问修正AI 也可能给"能用但不好用"的答案

想给 #wySw4 加键盘方向键控制，但页面很长，希望只有轮播在可视区时按键才生效，怎么配？
AI 第一次回答：
keyboard: true
测试发现页面在别处按方向键也会切轮播、和页面滚动打架。
AI 修正：写成对象并加 onlyInViewport：
keyboard: { enabled: true, onlyInViewport: true }
验证结论（一句话） 滚动到轮播区域按 ArrowRight 翻页生效；轮播不在视口时按键不误触发；爱达·魔都号第 6 张在四个轮播正常显示、图片 200，控制台无报错。✅

答辩四问 · 自答课堂分就在这四问里

① 这段代码什么意思？
keyboard 模块监听 document 的方向键事件；enabled: true 开启功能；onlyInViewport: true 限定只有轮播容器在可视区内才响应，避免长页面滚动时误触发。
② AI 第一次给的哪里不对、你改了什么？
AI 给的 keyboard: true 是全局生效——页面任何位置按方向键都会切轮播。我把简写改成对象写法，补 onlyInViewport: true 限定视口。
③ 新参数的作用？
onlyInViewport 让键盘监听"看位置"：轮播滚出视口就忽略按键，滚回来才恢复，这是简写形式给不了的精细控制。
④ 现场把 delay 改成指定值并解释预期变化？
把 autoplay.delay 从 3200 改成 1600：自动翻页间隔缩短一半，动画时长 speed: 800 不变，观感更急促；因为配置抽成了共用函数 jx530_sw4Config(fx)，改一处，初始和所有效果重建后都生效。
